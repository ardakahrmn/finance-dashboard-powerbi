# Financial Performance Dashboard | Power BI

An interactive financial analytics dashboard built in Power BI, analyzing revenue, profit, and budget performance for a technology/SaaS company across products, regions, and time.

## Overview
This dashboard transforms raw financial data into executive-level insights. It tracks revenue growth, profitability, budget achievement, and product-level margins, with full interactive filtering by year, product line, and region.

## Key Metrics (KPIs)
- Total Revenue, Total Net Profit, Net Margin %
- Budget Achievement %, Total Budget

## Visualizations
- **Revenue Trend by Year** — revenue growth over 2022–2024
- **Profit Margin by Product Line** — margin comparison (SaaS & Cloud lead; Hardware lowest)
- **Revenue by Region** — North America, Europe, Asia-Pacific, Latin America
- **Revenue vs Budget** — gauge showing actual vs target
- **Net Profit by Product Line** — profit contribution breakdown
- **Interactive slicers** — filter by Year, Product Line, and Region

## Tools & Techniques
- **Power BI Desktop** — data modeling, dashboard design, dark-theme UI
- **DAX** — custom measures (Net Margin %, Budget Achievement %, etc.)
- **Power Query** — data cleaning, type & locale handling
- **Design** — custom gradient background, consistent color system, KPI hierarchy
